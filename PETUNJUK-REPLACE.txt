EWS-DigitTwin - FILE REPLACE

Cara pakai:
1. Extract ZIP ini.
2. Copy seluruh isi folder ke ROOT repo EWS-DigitTwin Anda.
3. Pilih Replace/Overwrite jika Windows meminta konfirmasi.
4. Pastikan struktur src/components tetap sama.
5. Di root repo jalankan:

   npm run build

6. Jika build sukses:

   git status
   git add .
   git commit -m "Fix MQTT device status and wind kmh display"
   git push

7. Di Render pastikan environment:
   NODE_ENV=production
   MQTT_TOPIC=digitaltwin/lokasi1/data
   MQTT_STATUS_TOPIC=digitaltwin/lokasi1/status

8. Render -> Manual Deploy -> Clear build cache & deploy (atau deploy commit terbaru).

Target log:
[MQTT RX] digitaltwin/lokasi1/status
[MQTT DEVICE] AWS-B49793895DC0 | lokasi1 | ONLINE | wifi

Tidak boleh lagi muncul untuk /status:
Invalid telemetry packet schema received
